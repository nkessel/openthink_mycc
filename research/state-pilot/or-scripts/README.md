# Oregon research scripts (2026-10-13)

Run from a scratch folder (paths inside assume `/home/claude/or`): `scan.py` (homepages: towns, dates),
`scan2.py` (contact/about pages), `tribe.py` (event-calendar feeds), `build.py` (groups + coalitions),
`events.py` (events/projects/actions → or.json). Logos: `runlogos.py` (scripts/fetch-logos.py, robots.txt
respected), `zerologos.py` (logos on the ZERO Coalition and Energize Bend partner pages), `orcahlogos.py`.
`pf.py` is the robots.txt-respecting fetcher. Accepted logos and their source URLs: research/logos/or-accepted.json.
`master.py` = coalition membership lists; `info.py` = per-group town/type/description.
